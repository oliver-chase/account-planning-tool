# Sharing

Sharing: portable. The tool runs on any account's Excel workbook with no login and no server, so other people can use it.

What is in place for sharing:

- A license: MIT (`LICENSE`) for the tool's own code, and the bundled SheetJS library under Apache 2.0, both named in the README
- A security contact in the README
- The owner's board settings live in a local, git-ignored `docs/backlog-config.json`, with `docs/backlog-config.example.json` as the template
- The repository is public, and its history carries no personal addresses. New commits use a neutral noreply author set in the local git config

The navy and pink palette and the sample company and people names are the default look and stay as they are.
